# 机制相关

## 机制[​](#机制 "机制的直接链接")

| 机制 | 说明 |
| --- | --- |
| **蓄力机制** | 通过原版蓄力机制对所造成的伤害进行相同幅度的削弱，近战及远程等伤害均受蓄力 影响，可通过 **蓄力加成** 提高蓄力强度 ([**详细说明**](/docs/attributeplus/ji-zhi-xiang-guan/xu-li-ji-zhi)) |
| **盾牌机制** | 还在因为盾牌右键可以无敌而禁用盾牌吗，这个机制完美解决这个问题，该机制不是  禁止盾牌右键，而是加入冷却机制 ([**详细说明**](/docs/attributeplus/ji-zhi-xiang-guan/dun-pai-ji-zhi)) |
| **弓箭机制** | 可修改默认箭矢飞行速度以及精准度，通过 **箭矢速度 箭术精准** 提高箭矢飞行速度以及  精准度，同时精准度与飞行速度也受蓄力强度影响，1.14+ 支持 **箭矢穿透** 属性 ([**详细说明**](/docs/attributeplus/ji-zhi-xiang-guan/gong-jian-ji-zhi)) |
| **召唤机制** | **MythicMobs** 附属功能，可设置通过 **summon** 所召唤出来的怪物继承召唤者某一些属性  继承强度按 **召唤强度** 属性值强度继承 ([**详细说明**](/docs/attributeplus/ji-zhi-xiang-guan/zhao-huan-ji-zhi)) |
