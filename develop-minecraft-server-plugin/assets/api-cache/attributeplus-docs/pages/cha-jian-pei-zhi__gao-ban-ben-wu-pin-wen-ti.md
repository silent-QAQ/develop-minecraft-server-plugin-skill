# 高版本物品问题

## 为什么高版本的新物品无法读取到属性呢？[​](#为什么高版本的新物品无法读取到属性呢 "为什么高版本的新物品无法读取到属性呢？的直接链接")

高版本的用户可能会发现下界装备等新物品无法读取到属性，解决方法很简单在插件 **plugin.yml** 内增加一条 **api-version: <版本>** 即可，这里的 **版本** 建议对应自己服务器版本 **1.13.1** 的话就填 **1.13** 如果是 **1.16.5** 那么就填 **1.16** 即可，感谢由 **YiMiner** 提供的方法

右键 **插件JAR** 后用 **压缩包方式** 打开插件即可找到 **plugin.yml** 配置
