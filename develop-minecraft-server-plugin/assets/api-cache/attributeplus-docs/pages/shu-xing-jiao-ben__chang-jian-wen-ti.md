# 常见问题

## 属性脚本注册后修改脚本内的属性名为什么服务器里面还是旧的属性名?[​](#属性脚本注册后修改脚本内的属性名为什么服务器里面还是旧的属性名 "属性脚本注册后修改脚本内的属性名为什么服务器里面还是旧的属性名?的直接链接")

> **服务器内属性名** 为 attribute.yml 内修改的属性名  
> **属性默认名** 为 属性脚本内所设属性名  
>   
> 属性脚本 内的 **attributeName** 为 **属性默认名** 与 **服务器内属性名** 是不同的，所以你不需要去修改脚本内的属性名，你只需要去 **attribute.yml** 内修改即可，请阅读 [**属性名**](/docs/attributeplus/kai-fa-wen-dang/attributecomponent/shu-xing-ming-shuo-ming) 这一页的内容
