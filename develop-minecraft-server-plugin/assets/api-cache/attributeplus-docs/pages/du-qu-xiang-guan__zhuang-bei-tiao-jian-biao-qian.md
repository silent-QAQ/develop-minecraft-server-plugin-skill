# 装备条件标签

## 说明[​](#说明 "说明的直接链接")

只有满足装备上的条件标签，插件提供 **装备等级、职业、装备类型** 三个条件标签  
什么? 插件就这三个条件标签而已吗？ **当然不止，只要你有**[**开发**](/docs/attributeplus/kai-fa-wen-dang)**能力，可以开发其他的条件标签**

## 条件标签[​](#条件标签 "条件标签的直接链接")

| 标签名 | 说明 |
| --- | --- |
| 装备等级 | 使用者等级必须大于等于条件，例如 **"装备等级: 100",** 可使用范围格式，如 "**装备等级:** **10-100**" |
| 装备类型 | 必须装备再指定位置上才行，例如 **"装备类型: 副手"** |
| 职业 | 使用者必须拥有其中一项条件，例如 **"职业: 剑士/狂战士"** 满足其一即可  直接给玩家 "剑士" 权限即可，格式可以是 "**ap.剑士** 或 **剑士**" |

## 配置内容[​](#配置内容 "配置内容的直接链接")

```
#权限限制  
#支持多个权限，例如 "职业: 剑士/法师/牧师" 只需要满足其一即可  
permission:  
  split: "/"  
  key: "职业"  
#装备等级限制  
#支持 10-100 的范围格式,即10至100级内玩家可使用(3.3.0.7+)  
level: "装备等级"  
#装备等级限制标签,等级来源变量  
level-placeholder: "%player_level%"  
#装备类型  
#例如 [装备类型: 双持]  
equipmentType:  
  lore: "装备类型"  
  list:  
    - "双持"  
    - "主手"  
    - "副手"  
    - "头盔"  
    - "衣服"  
    - "裤子"  
    - "鞋子"
```
