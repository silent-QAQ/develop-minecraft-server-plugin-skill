# 旧读取格式相关 (<=3.3.0.6)

## 读取格式[​](#读取格式 "读取格式的直接链接")

| 格式 | 说明 |
| --- | --- |
| <属性名> <值> | 读取属性固定值 |
| <属性名> <值>-<值> | 读取属性最小值跟最大值 |
| <属性标签内容> / <条件> | [内嵌式条件读取格式](/docs/attributeplus/du-qu-xiang-guan/shu-xing-du-qu-tiao-jian) |

## 可不可以将属性值加在左侧呢?[​](#可不可以将属性值加在左侧呢 "可不可以将属性值加在左侧呢?的直接链接")

当然可以，你可以是 **<值> <属性名> 、 <属性名> <值>** 当然你也可以设置一些其他符号，例如 **+<值> <属性名>**

## 我能不能自己创建新的读取方式呢？[​](#我能不能自己创建新的读取方式呢 "我能不能自己创建新的读取方式呢？的直接链接")

当然可以，但你必须掌握 **Java、Kotlin** 其中一门编程语言，如果你是服主且不具备开发能力，这边建议你去找其他开发者进行定制  
读取组件为 **DescriptionRead** ([开发文档](/docs/attributeplus/kai-fa-wen-dang))
