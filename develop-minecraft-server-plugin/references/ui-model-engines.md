Use this file only when the requested plugin explicitly integrates one of these engines. These APIs are large, version-sensitive, and used less frequently, so keep only their documentation entry points in the skill and consult the matching website on demand.

## Usage Rule

Do not preload, mirror, or summarize an engine's full documentation during ordinary plugin work. Open only the relevant official page when that engine is actually requested, confirm the installed engine/client version, and do not invent method signatures or parameters.
